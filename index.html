复旦大学 CTF 校队

六星战队（******）是由复旦大学计算机科学技术学院学生组成的网络安全 CTF 战队。战队长期活跃于国内外各大 CTF 竞赛，并作为 XCTF 联赛社区战队主办 *CTF 国际赛。

网络安全爱好者的聚集地

我们是一群对网络安全充满热情的同学，研究方向覆盖二进制漏洞挖掘与利用、Web 渗透、密码学、逆向工程、区块链安全等领域，让每一位安全爱好者都能找到属于自己的舞台。

我们的方向

CTF 六大经典方向，总有一个适合你

Pwn

二进制漏洞利用

挖掘并利用程序中的内存破坏漏洞，劫持控制流，夺取系统权限。

Web

Web 安全

研究 Web 应用中的注入、越权、反序列化等漏洞，攻破层层防线。

Rev

逆向工程

拆解二进制程序，还原程序逻辑，与混淆和加壳斗智斗勇。

Crypto

密码学

分析密码算法的设计与实现缺陷，用数学破解加密的秘密。

Misc

安全杂项

取证分析、隐写、编码等包罗万象的安全技术，考验知识的广度。

Chain

区块链安全

研究智能合约与区块链系统的安全问题，探索 Web3 时代的攻防。
